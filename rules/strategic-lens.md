# Strategic Lens

Every product decision should be tested against five questions. If the answer to any is "no" or "unclear", the decision needs a second look — not necessarily a veto, but a deliberate call.

1. **Does it serve the user's unified journey?**
   Not a department's silo. Not a feature roadmap. The end-to-end experience of the person you're building for.

2. **Does it connect to the platform?**
   Or does it create a new fragment? Every new surface that doesn't connect back is a future migration cost.

3. **Does it scale to the next milestone?**
   Pick the next major moment that matters — a launch, a season, an event, a fundraise. If the decision doesn't survive that load, scope it differently.

4. **Does it honour the brand promise?**
   Quality, depth, dignity, voice — whatever you've promised. A decision that's right in isolation but breaks the brand is wrong.

5. **Does it bridge the core product to its broader ecosystem?**
   Every product sits inside a larger context — community, content, partnerships, distribution. A decision that ignores the bridge usually leaves value on the table.

## How to use it

- Run all five before committing to a non-trivial decision.
- A clean "yes" on all five = ship.
- A "no" on one = scope adjustment usually fixes it.
- "No" on two or more = stop, reconsider the framing.
- This is a *filter*, not a *generator*. The lens stress-tests ideas. It doesn't invent them.

## Why these five

These aren't universal — they're the five that consistently catch the failure modes I see most. If your organisation's failure modes are different, edit the lens. The discipline matters more than the questions: pick five, write them down, run every decision through them.
