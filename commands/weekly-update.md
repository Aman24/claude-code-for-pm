# /weekly-update — Recurring Leadership Update Prep

Prepare the executive update for the recurring leadership meeting.

## Steps

1. Launch the `exec-update-writer` agent to scan all products and draft the update
2. Review the draft and refine based on any additional context from the user
3. Save the final update to `docs/plans/weekly-update-{{date}}.md`
4. Present a clean summary with talking points you can use in the meeting

## Output
- Per-product status table (1 line each)
- Top 3-5 talking points (lead with wins, then risks, then asks)
- Any cross-product items needing exec attention
- Action items from last meeting (if available)
