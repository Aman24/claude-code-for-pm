## How to use this template

Write the spec **before** building. Skip it for explorations, quick analyses, and sub-1hr tasks — but use it for anything that takes more than a day or touches more than one system.

A spec that fits on one screen is doing its job. If yours is sprawling, you're using it as a PRD — split the two: the PRD captures *why*, the spec captures *how*.
